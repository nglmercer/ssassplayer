Thumbnail Preview on Hover

Hover over the progress bar to see frame previews. This example uses two strategies:

1. VTT Sprite Sheet (YouTube-style)

Pre-generate a sprite sheet and VTT file server-side. The VTT maps time ranges to positions in the sprite.

import { createVttThumbnailPlugin } from 'ssassplayer';

await player.usePlugin(createVttThumbnailPlugin({
  vttUrl: '/thumbnails.vtt'
}));

2. Manual Sprite Configuration

If you already have sprite sheets, configure them directly:

await player.usePlugin(createVttThumbnailPlugin({
  sprites: [{
    url: '/thumbs/sprite.jpg',
    width: 1600,
    height: 900,
    tileWidth: 160,
    tileHeight: 90,
    interval: 10
  }]
}));

VTT File Format

WEBVTT

00:00:00.000 --> 00:00:10.000
sprite.jpg#xywh=0,0,160,90

00:00:10.000 --> 00:00:20.000
sprite.jpg#xywh=160,0,160,90

00:00:20.000 --> 00:00:30.000
sprite.jpg#xywh=320,0,160,90
